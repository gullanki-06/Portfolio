03Projects

Robotics · Computer VisionIn progress

SwarmSight: Vision-Based Search & Rescue Robot

A rocker-bogie rover that searches disaster zones for survivors. A fine-tuned YOLO11n model detects people and individual body parts, so someone partly buried under rubble can still be found from a visible hand or leg. Runs on a Raspberry Pi 5 CPU via NCNN, avoids obstacles with ToF sensors and maps where people were detected.

Path planning for a team of rescue robots framed as an optimisation problem that minimises rescue time and obstacle penalties. Built a 2D multi-robot environment with swarm exploration, victim detection and a Standard PSO baseline, then extended it with adaptive inertia and learning factors to avoid stagnation.

Networks · Continual LearningIn progress

Mission-Aware Continual Learning for SDR Emergency Networks

An AI packet scheduler for GNU Radio that ranks emergency traffic by a Dynamic Mission Criticality Score instead of fixed QoS classes, so an SOS is never stuck behind telemetry. Uses gradient boosting and online learning that adapts in the field, plus a trust layer that stops spoofed nodes from faking priority.
